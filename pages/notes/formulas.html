Binary operations

Associative Property

\(a \odot (b \odt c) = (a \odot b) \odt c\)

As a useful way to remember this is you can pick the order of who you talk to.

Commutative Property

\(a \odot b = b \odot a\)

As a useful way to remember this is COMMUnication happens both ways.

Distributive Property

\(a * (b + c) = a*b + a*c\)

Note that for some operations you may have only left or only right distributive.

Identity Property

For addition we have:

\(a + 0 = a\)

For multipication we have:

\(a * 1 = a\)

In general we have:

\(a + b = a\)

Inverse Property

For addition we have:

\(a + b = 0\)

For multipication we have:

\(a * b = 1\)

In general we have:

\(a + a^{-1} = i\)
